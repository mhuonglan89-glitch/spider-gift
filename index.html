🚀 Đưa web lên GitHub & Vercel (Người nhận mở ở đâu cũng thấy ảnh của bạn)

Trang web này là Zero-Server Static Web, Vercel triển khai cực nhanh trong vài giây!

Khuyên Dùng Cho GitHub & Vercel
1. Tải file config.js (Đã chứa toàn bộ ảnh & lời chúc của bạn)

Bấm nút bên dưới để tải file config.js về máy. Bạn chỉ cần thả file này vào thư mục dự án flower-gift-web rồi chạy git push là Vercel sẽ tự động hiện toàn bộ ảnh của bạn!

Dự phòng
2. Sao chép trực tiếp mã cấu hình

Nếu bạn không muốn tải file, bấm nút này để copy toàn bộ mã cấu hình đã kèm ảnh vào Clipboard (sau đó gửi cho trợ lý hoặc dán vào file config.js).

🐙 Hướng dẫn lệnh Git để đẩy lên GitHub & Vercel:
  1. Tải file config.js ở trên và bỏ vào thư mục flower-gift-web.
  2. Vào GitHub tạo 1 repository mới (ví dụ: tang-no-spiderman).
  3. Mở terminal tại thư mục này và chạy các lệnh: 
    git add .
git commit -m "Cập nhật web quà tặng No"
git remote add origin https://github.com/TÊN_GITHUB/TÊN_REPO.git
git push -u origin main
  4. Vào Vercel -> Import Repository vừa tạo -> Bấm Deploy (Vercel tự nhận diện web tĩnh và chạy ngay lập tức)!

🚀 Hướng Dẫn Up Web Miễn Phí (Không Cần Server)

🌟 Cách 1: Netlify Drop (Đơn giản nhất - 30 giây là xong)

  • Bước 1: Trong bảng "Chỉnh sửa", chỉnh ảnh và lời chúc của bạn, sau đó bấm "Tải File Web Hoàn Chỉnh".
  • Bước 2: Dùng trình duyệt truy cập: https://app.netlify.com/drop (hoàn toàn miễn phí, không cần thẻ).
  • Bước 3: Kéo thả file index.html bạn vừa tải vào ô kéo thả trên trang web đó.
  • Bước 4: Netlify sẽ tạo ngay 1 đường link online (ví dụ: https://tang-nguoi-thuong.netlify.app). Bạn chỉ cần copy link đó gửi qua tin nhắn cho người yêu!

🌟 Cách 2: Vercel hoặc GitHub Pages

  • Nếu bạn có tài khoản GitHub, chỉ cần tạo 1 Repository mới, tải file lên và bật GitHub Pages ở mục Settings.
  • Hoặc đăng nhập Vercel.com và kéo thả thư mục dự án lên, link chạy siêu tốc toàn cầu.

🌟 Cách 3: Mở trực tiếp trên máy hoặc gửi qua AirDrop / Telegram

  • File HTML tự chứa toàn bộ dữ liệu, người nhận chỉ cần mở bằng Safari (iPhone) hoặc Chrome là chạy mượt mà không cần mạng Internet!
